# Parameters

`parameters()` declares the named inputs that the runtime resolves before features execute.

## Current support

- numeric values with units
- expressions with units

## Example

```ts
parameters({
  width: { kind: 'number', value: 10, unit: 'mm' },
  height: { kind: 'expression', expression: 'width * 2', unit: 'mm' },
});
```
