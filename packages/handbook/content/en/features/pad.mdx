# Pad

`pad()` is the first sketch-driven solid feature in the current product slice.

## Inputs

- `sketch`
- `length`
- `direction`

`length` accepts a literal value, an expression, or a parameter reference. `direction` controls whether the extrusion goes `up`, `down`, or `symmetric` around the sketch plane.

## Example

```ts
sketch({
  id: 'sketch_1',
  plane: 'xy',
  svg,
  constraints,
});

pad({
  id: 'pad_1',
  sketch: feature('sketch_1'),
  length: reference('height'),
  direction: 'up',
});
```

## Dual-write behavior

In the authoring workspace, editing a pad in the inspector rewrites the same `pad(...)` call in source.
