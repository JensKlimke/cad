# Edit, build, inspect

Use this workflow for the current product baseline.

1. Open a project document.
2. Edit `document.ts` or use the tree and inspector.
3. Save and build.
4. Inspect the viewport result and resolved parameters.
5. Fix diagnostics if the build fails.
