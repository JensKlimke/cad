# Repair a Reference

When a selected face no longer resolves, the workspace shows the failed selector diagnostics and candidate entities.

1. Rebuild the document.
2. Open the reference panel.
3. Review the resolver layer and candidate list.
4. Pick the intended replacement entity.
5. Apply the repair so the source stores the updated handle.

Most edits should resolve automatically through finder or construction fallback. Repair is for genuinely ambiguous topology changes.
