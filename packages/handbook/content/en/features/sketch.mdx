# Sketch

`sketch()` persists the Slice 5 rectangle-first sketch subsystem: plane, canonical SVG, and width/height bindings.

## Current slice behavior

- sketch mode opens from the feature inspector
- drawing or redrawing the rectangle rewrites canonical `document.ts`
- width and height can be literal millimetres, parameter references, or expressions
- the runtime builds sketch-only documents successfully even when no 3D tessellation exists yet

## Example

```ts
sketch({
  id: 'sketch_1',
  plane: 'xy',
  svg: '<svg xmlns="http://www.w3.org/2000/svg" viewBox="-20 -20 120 90" data-cad-plane="xy" data-cad-kind="rectangle">  <rect x="0" y="0" width="80" height="50" fill="none" stroke="currentColor" stroke-width="1" /></svg>',
  constraints: {
    kind: 'rectangle',
    anchor: 'origin',
    width: { kind: 'reference', name: 'width' },
    height: { kind: 'expression', source: 'height', unit: 'mm' },
  },
});
```
