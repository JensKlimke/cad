# Define document

`defineDocument()` is the top-level SDK call that returns the canonical document module shape.

## When to use it

Use it once, as the default export of `document.ts`, after declaring parameters and body features.

## Example

```ts
export default defineDocument({
  parameters: parameters({}),
  body: body([]),
});
```
